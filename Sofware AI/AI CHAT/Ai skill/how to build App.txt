> ⚠️ Note: Do not write any code yet. Just give me the plan and structure."**

مرحلہ نمبر 2: اصول طے کرنا (The Golden Rules)
مقصد: یہ سب سے اہم اسٹیپ ہے۔ سٹرکچر ملنے کے بعد، کوڈ شروع کرنے سے پہلے یہ پرومپٹ دیں تاکہ AI "چھوٹا کوڈ" لکھنے کی غلطی نہ کرے۔
یہ پرومپٹ کاپی کریں:
> **"Great. Now act as an Expert Full-Stack Developer. We will write the code file by file.
> ⚠️ STRICT RULES FOR CODING (READ CAREFULLY):
>  * No Placeholders: Never use comments like `` or // Rest of code. You must write the FULL, working code.
>  * Production Level: The code must be clean, bug-free, and fully responsive.
>  * Length: Do not shorten the code. If the code is too long, stop and ask me to continue, but do not skip lines.
>  * One File at a Time: Only provide code for the file I ask for.
> Acknowledge if you understand these rules."**
>

حل نمبر 1: کوڈ کو الگ الگ فائلوں میں ہی رکھیں (بہترین طریقہ)
پروفیشنل طریقہ یہی ہے کہ HTML، CSS اور JS الگ الگ فائلوں میں ہوں۔ اس میں کوئی مسئلہ نہیں آتا اگر آپ کے فولڈر میں فائلوں کے نام وہی ہوں جو کوڈ کے اندر لکھے ہیں۔
طریقہ:
 * اپنے کمپیوٹر پر ایک فولڈر بنائیں۔
 * اس میں 3 فائلیں بنائیں: index.html, style.css, script.js
 * کوڈ پیسٹ کریں۔
مسئلہ کہاں آتا ہے؟
مسئلہ تب آتا ہے جب HTML فائل کو پتہ ہی نہ ہو کہ CSS یا JS فائل کہاں پڑی ہے۔ اس کنیکشن کو چیک کرنے کے لیے AI کو یہ پرومپٹ دیں:
🔹 پرومپٹ (لنکنگ چیک کرنے کے لیے):
اگر آپ نے الگ الگ کوڈ لے لیا ہے اور اب چاہتے ہیں کہ AI چیک کرے کہ یہ آپس میں جڑیں گے یا نہیں، تو یہ لکھیں:



> **"I have the separate codes for HTML, CSS, and JS.
> Please provide me the UPDATED <head> and <body> tags for my index.html file.
> Make sure it is correctly linked to style.css and script.js.
> Also, ensure the JavaScript is loaded properly (using defer or at the end of the body) so that buttons work correctly."**

لیکن! ان کو جوڑتے وقت اکثر AI غلطی کرتا ہے۔ اس لیے آپ کو یہ خاص پرومپٹ استعمال کرنی ہوگی:

1. پہلی پرومپٹ: (اگر آپ کے پاس کوڈ الگ الگ ہے اور آپ چاہتے ہیں AI خود جوڑ کر دے)
یہ پرومپٹ تب استعمال کریں جب آپ کے پاس HTML، CSS اور JS کا کوڈ موجود ہے اور آپ AI کو دے کر کہہ رہے ہیں کہ "بھائی ان کو ایک فائل میں مکس کر دو۔"
یہ پرومپٹ کاپی کریں:


> **"Act as a Web Developer. I have separate codes for HTML, CSS, and JavaScript.
> Please combine/merge them into a SINGLE index.html file.
> ⚠️ Follow this structure strictly:
>  * Start with the standard HTML structure.
>  * Put all the CSS code inside <style> tags within the <head> section.
>  * Put all the HTML body content inside the <body> tags.
>  * Put all the JavaScript code inside <script> tags at the very end, just before the closing </body> tag.
> Do not use external links (like <link href...> or <script src...>). Just give me one complete copy-pasteable code block."**
>

> Inside the code, write clear COMMENTS in capital letters like:

>  * ``
>  * ``
